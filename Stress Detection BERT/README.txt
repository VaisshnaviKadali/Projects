# Stress Detection using NLP and BERT

## Overview
This project focuses on detecting stress levels from social media text using Natural Language Processing (NLP) and deep learning techniques. The system analyzes textual patterns, emotions, and sentiments to classify whether a user is experiencing stress.

The project uses BERT-based contextual embeddings to improve prediction accuracy and understand semantic meaning in text data.

---

## Features
- Text preprocessing and cleaning
- Sentiment and emotion analysis
- Stress classification using BERT
- Data visualization and analysis
- Context-aware prediction system
- Performance evaluation using accuracy metrics

---

The project uses social media text datasets containing stress-related posts and emotional interactions for training and testing the model.
