Stock Price Forecasting using XGBoost, Prophet and ARIMA

Project Overview
This project performs stock price forecasting using machine learning and time-series analysis techniques. Multiple forecasting models including XGBoost, Prophet, and ARIMA were implemented and compared to evaluate prediction performance and trend forecasting capabilities.

Objectives
- Analyze historical stock market data
- Forecast future stock prices
- Compare forecasting performance of multiple algorithms
- Study trend and seasonality patterns

Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- XGBoost
- Prophet
- ARIMA
- Statsmodels
- Scikit-learn

Dataset
Historical stock market data was used to train and evaluate forecasting models.

Methodology
1. Data Collection
2. Data Preprocessing
3. Exploratory Data Analysis
4. Feature Engineering
5. Model Training
6. Forecast Generation
7. Comparative Analysis

Models Used
- XGBoost
- Prophet
- ARIMA

Results
- Achieved **88% forecasting accuracy**
- Compared trend forecasting performance across models
- Evaluated seasonality and market behavior patterns

Future Enhancements

- Deep learning models (LSTM)
